PATCH — SCORECARD / PONTOS REALIZADOS
====================================

Objetivo
--------
Corrigir a origem dos valores mensais e o cálculo/exibição dos pontos realizados
no Scorecard administrativo.

Principais correções
--------------------
1. O Scorecard passa a procurar a publicação mais recente que realmente contém
   o mês solicitado. Caso a publicação ativa seja parcial, o sistema recupera o
   valor válido de uma versão anterior.
2. A API agora devolve separadamente os valores publicados (sourceValues) e os
   valores efetivos após ajustes manuais. O botão "Puxar" restaura de verdade o
   valor do módulo, inclusive após salvar um snapshot manual.
3. IDP não publica mais 0% quando não existe linha de base no mês. Esses períodos
   passam a ser tratados como "Sem dados".
4. IDP e RDO preservam duas casas decimais, evitando que 89,55% vire 90% ou que
   79,60% vire 80% antes da comparação com a meta.
5. RDO sem relatórios emitidos não é convertido em resultado 0%.
6. RNC preserva duas casas decimais no tempo médio, evitando arredondamento
   indevido junto à meta de 15 dias.
7. Foram adicionados testes unitários para publicação histórica, precisão e
   tratamento de ausência de dados.

Instalação
----------
1. Extraia este ZIP na raiz do projeto.
2. Confirme a substituição dos arquivos existentes.
3. Execute:

   pnpm test
   pnpm build

Após o deploy
-------------
Publique novamente os módulos IDP, RDO e RNC para gerar novos snapshots com a
precisão e o tratamento de ausência de dados corrigidos. Não é necessária
migração de banco de dados.
